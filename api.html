API Documentation

REST over HTTPS. Send a multipart upload or a JSON body. Every request needs an API key.

Base URL: https://api.mdeobf.com

API key required Mandatory

An API key is strictly required for every request. Any unauthenticated call will be rejected. Request your API key by joining our Discord server.

Only method: HTTP header

X-Api-Key: YOUR_API_KEY
