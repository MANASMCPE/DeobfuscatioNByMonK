Reference

API docs.

One REST endpoint for all deobfuscation, detection, and formatting. Free with an API key from the Discord server.

Authentication

Every request must carry your personal key in the X-Api-Key header. Keys are free — request one in the Discord.

X-Api-Key: leakd_xxxxxxxxxxxxxxxx

Missing or invalid keys return 401 Unauthorized. Free keys are rate-limited to 20 requests / minute.

Deobfuscate

Send a script and an engine name. The engine accepts any of the tools listed on the Tools page — case-insensitive.

POSThttps://leakd.vercel.app/api/deobfuscate

Request body

{
  "code":   "local a=... -- obfuscated",
  "engine": "luraph",   // or "auto"
  "format": "text"       // "text" | "json"
}

Response

{
  "success":    true,
  "engine":     "luraph",
  "detected":   "Luraph v15.1",
  "output":     "-- deobfuscated source here",
  "duration_ms": 482
}

Detect

Identify the obfuscator used by a script without attempting deobfuscation.

POSThttps://leakd.vercel.app/api/detect
{
  "code": "local a=... -- script to identify"
}
{
  "success":     true,
  "obfuscator":  "Prometheus",
  "confidence":  0.98,
  "version":     "v4.7"
}
