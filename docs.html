What is deobfuscation?

Obfuscation is a technique that transforms readable Lua source into code that is functionally equivalent but difficult to understand. Deobfuscation is the reverse: recovering readable source from an obfuscated script.

LeakD brings together dozens of specialized deobfuscators under one interface — web tools and a free REST API. Every tool is designed for static recovery: nothing is executed, no sandbox is required, and results are deterministic.

Picking the right tool

Not sure which obfuscator produced a given script? Run the Detector first. It fingerprints the script against 40+ signature families and returns the most likely match with a confidence score.

  • Run Detector on the script → note the obfuscator and version.
  • Open Tools, pick the matching engine.
  • Paste or upload the script → hit Deobfuscate.

Using the API

The API mirrors the web tools exactly. Every engine exposed in the UI is available as a POST endpoint under /api/.

Full endpoint reference, rate limits, and error codes live on the API Docs page.

FAQ

Is it really free?

Yes. Keys are free, distributed through the Discord server, with a rate limit of 20 requests per minute per key.

Are my scripts stored?

No. Scripts are processed in ephemeral containers and are never written to persistent storage.
