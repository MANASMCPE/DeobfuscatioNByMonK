How it works

Three moves, no account.

  1. 01

    Drop the script

    Upload a .lua file or paste raw code straight into the bench. Nothing to install.

  2. 02

    Pick the protection

    Choose the obfuscator, or let the Detector name it first, then run the matching deobfuscator.

  3. 03

    Read the source

    Copy the output, download the .lua, or call the same endpoint from your own stack.
